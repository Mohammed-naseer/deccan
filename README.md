# Deccan Space Works — Invisible Grills Website

A production-grade, premium product website for **Deccan Space Works**, specializing in **Invisible Grills** in Hyderabad.

## 🌐 Live Pages

| Page | Route |
|------|-------|
| Main Landing Page | `/` |
| Customer Tracking Portal | `/customer/dashboard` |
| Admin Management Dashboard | `/admin/dashboard` |

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router, TypeScript)
- **Styling**: Tailwind CSS (custom architectural dark theme)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Inter + Outfit (Google Fonts)

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📋 Environment Variables

Create a `.env.local` file to connect a real backend:

```env
NEXT_PUBLIC_API_BASE_URL=https://your-api-url.com
```

Without this, the app uses built-in mock data.
